# Автоматизация тестирования UI и API (Playwright)

Проект по автоматизации тестирования веб-приложения (UI) и сервиса маркетплейса (API) с настроенным CI/CD пайплайном.

## 🛠 Стек технологий
* **Язык:** JavaScript
* **Фреймворки:** Playwright, Faker.js
* **CI/CD:** GitHub Actions
* **TMS & Отчеты:** Allure TestOps, Allure Awesome Report
* **Уведомления:** Telegram Bot

---

## 💻 Покрытый функционал

### 🌐 UI Тесты (https://realworld.qa.guru/)
* Регистрация нового пользователя с генерацией данных через Faker.js
* Создание, редактирование и удаление публикаций (статей)
* Добавление и удаление комментариев к статьям

### ⚙️ API Тесты (https://www.qacloud.dev/market)
* Получение полного списка товаров (`GET`)
* Создание карточки товара со всеми полями (`POST`)
* Негативный тест на валидацию температурной зоны (`POST`)
* Фильтрация товаров по нескольким категориям (`GET`)
* Частичное обновление стоимости товара (`PUT`)

---

## 🚀 Локальный запуск

Установка зависимостей и браузеров:
* `npm ci`
* `npx playwright install --with-deps`

Команды для запуска:
* `npx playwright test` — запустить все тесты
* `npx playwright test --ui` — запустить только UI тесты
* `npx playwright test --api` — запустить только API тесты
